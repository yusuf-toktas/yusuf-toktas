## 🚀 Featured Projects

### [wasm-dap](https://github.com/yusuf-toktas/wasm-dap)

**A source-level debugger, execution tracer, and module inspector for WebAssembly.**

Built with Rust and Wasmtime, wasm-dap brings source-level debugging to WebAssembly through the Debug Adapter Protocol.

It provides breakpoints, step debugging, variable inspection, execution tracing, and more.

`Rust` · `WebAssembly` · `Wasmtime` · `DAP`

---

### [PyPath Inspector](https://github.com/yusuf-toktas/pypath-inspector)

**A local-first diagnostic tool for Python environments.**

Helps developers understand their Python installations, command resolution, PATH configuration, pip mismatches, and virtual environments.

Designed to be strictly read-only, offline, and dependency-free.

`Python` · `CLI` · `Diagnostics` · `Cross-platform`
